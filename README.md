# FlyRank CTR Opportunity Scoring Model

This repository contains the machine learning capstone project for the FlyRank ML Internship. 

## Project Overview
The goal of this project is to build a machine learning model that predicts expected Click-Through Rates (CTR) based on search volume and average position. By comparing expected clicks to actual clicks, we identify high-visibility pages that are under-capturing traffic.

## Folder Structure
- `/work`: Contains the Jupyter notebooks for EDA, feature engineering, and modeling.
- `/docs`: Contains the deployed research paper.
- `/submission`: Contains the final deployed URL of the paper.

## How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Open and run the notebook inside the `/work` folder.
